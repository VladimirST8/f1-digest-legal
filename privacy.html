Privacy Policy

F1 Local Digest is a personal automation tool run locally by a single operator. It is not distributed to, or used by, any other person.

The tool requests access to Google Drive scoped to drive.file — meaning it can only read or write files it itself creates, never the operator's other Drive content — in order to upload a daily HTML digest file to the operator's own Google Drive.

No data is collected from, shared with, or sold to any third party. Data fetched from public web sources during a run (news article text) is processed locally and is not retained beyond generating the digest file.
